## About
A beginner-friendly Python Streamlit project demonstrating AI Flashcard Generator.

## Run
1. Install Python 3.10 or newer.
2. Open this folder in VS Code.
3. Run `pip install -r requirements.txt`.
4. Set `GROQ_API_KEY` in a `.env` or `.env.flashcard` file, or in Streamlit secrets.
5. Run `streamlit run app.py`.
6. Open the local URL shown in the terminal.

**Note:** API calls require internet, a valid API key, and any applicable quota or billing. Never upload `.env` or `.env.flashcard` to GitHub.
